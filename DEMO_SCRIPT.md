>
> *When an AI agent or ChatGPT in-app browser loads this tab, it immediately discovers our machine manifest at `/.well-known/webmcp.json`. Agents can inspect the full graph topology, query available components through `search_products`, calculate GPU VRAM sizing, and even trigger automated topological auto-alignment with zero wire crossings."*

1. **Resolution**: Record in **1080p (1920x1080)** or **1440p** in Google Chrome or Microsoft Edge.
2. **Audio**: Use a quiet room and speak with enthusiastic, clear energy.
3. **Pacing**: Follow the second markers closely. Don't linger on any single modal for more than 15 seconds.
4. **YouTube Settings**:
   * **Title**: `OmniFlow Studio — WebMCP Collaborative Visual Cloud & Systems Studio (Demo)`
   * **Visibility**: **Public** or **Unlisted** (Make sure it is NOT Private so judges can watch it).
